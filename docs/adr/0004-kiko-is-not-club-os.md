# Kiko is not a Club OS integration

Kiko was a personal OpenClaw dump of one family’s race times, imported once into the BMSC Club. It is not how Clubs are provided, not a swim-module, and must not grow a `--club` flag or run for Apta. Remaining `db:import-kiko` / `kikoCode` code in the BMSC repo is frozen history. Meet integration for swim Clubs is Spectra.
