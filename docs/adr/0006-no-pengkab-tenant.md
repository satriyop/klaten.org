# No Pengkab tenant type; Perpani is a Club when it exists

Affiliation (KONI, Pengkab, Perpani) lives on the Listing. When Perpani gets a Hostname it is a Club like Apta: roster, hats, latihan, pengumuman, a different sport module. A parent Pengkab that can see many Clubs is a different product and is not designed into Apta or into the Club definition.
